# AcKeskin.github.io

Personal portfolio, live at https://ackeskin.github.io.

Plain HTML/CSS/JS, no build step. Edit `index.html`, `assets/css/redesign.css`, `assets/js/redesign.js`; push to `main` to deploy.

## Resume

Source: `docs/resume.tex`. Push a change to `main` and GitHub Actions builds `docs/Ali_Can_Keskin_Resume.pdf`. Local build: `pdflatex resume.tex` in `docs/`.
